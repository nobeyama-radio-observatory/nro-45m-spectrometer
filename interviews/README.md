# 聞き取りの記録

公開資料にない台帳の値（保守の手間、担い手の数、更新の見込みなど）を、保守の担い手に聞き取って集めた記録です。台帳（[assets.yaml](../assets.yaml)）の `sources` から、この記録の問いを指します。

## 書き方

- **1回の聞き取りを1ファイルにします。** 名前は `YYYY-MM-DD.md`。同じ日に2回あれば `YYYY-MM-DD-2.md` とします。
- **回答者が確認した要約を残します。** やり取りの書き起こしではありません。記録を公開する前に、回答者に中身を確かめてもらいます。
- **回答者は役割で書きます。** 名前、連絡先、個人の評価は書きません。
- **事実と見立てを分けます。** 答えのうち見立て（「〜になりそう」「おそらく〜」）に当たるものには `（見立て）` と添えます。台帳に移すときは `（仮説）` を添えます。
- **公開できない話は書きません。** 制御の手順、接続先、ネットワーク構成、契約の中身が出たら、記録から外します。保守の支援の有無は書いてよく、契約の中身は書きません。
- **「分からない」も記録します。** 答えが「不明」だった問いも残します。台帳では `未記入` のままにします。
- **書いた後は直しません。** 答えが変わったら、新しい日付の記録を足します。台帳は新しい記録を出典にして直します。

台帳からは、`interviews/2026-11-18.md 問3` のようにファイルと問いの番号で指します。

## 雛形

```markdown
# 聞き取り YYYY-MM-DD

| 項目 | 内容 |
|---|---|
| 日付 | YYYY-MM-DD |
| 回答者 | 役割（例：分光計の保守の担当） |
| 聞き手 | 人か AI か（例：AI（Claude）が問いを作り、会話で聞き取った） |
| 回答者の確認 | 済（YYYY-MM-DD） |
| 対象 | 台帳の id |

## 問いと答え

### 問1 （対象の id）：問いの要約

答えの要約。見立てには（見立て）と添える。

## 台帳への反映

| 問い | 台帳の id と項目 | 反映した値 |
|---|---|---|
```
